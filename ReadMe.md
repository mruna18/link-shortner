# 🔗 URL Shortener
A beautiful, responsive URL shortener built with Flask featuring user authentication, analytics, and a modern dark theme.

![App Screenshot](images/image1.png)

## Features
- **URL Shortening** - Create short links instantly
- **User Accounts** - Permanent URLs & advanced features
- **Guest Mode** - No registration required
- **Click Analytics** - Track your link performance
- **Responsive Design** - Works on all devices
- **Modern UI** - Dark theme with smooth animations

## Tech Stack
- Backend: Flask, SQLite
- Frontend: HTML, CSS, JavaScript
- Auth: Flask-Login
- Styling: Custom CSS with glass morphism

## Quick Start
```bash
git clone https://github.com/mruna18/link-shortner
cd url-shortener
pip install -r requirements.txt
python app.py
